# AgencyOS

**An AI-powered agency workflow platform.**

AgencyOS is a project focused on helping businesses organize service requests, coordinate AI-assisted workflows, and review generated deliverables in one place.

## Project Goals

- Accept and organize client briefs.
- Break requests into manageable tasks.
- Generate business deliverables using AI.
- Review outputs before they are approved.
- Track task status and execution history.

## Planned Technology Stack

- **Backend:** Python, FastAPI
- **Frontend:** React, TypeScript
- **Database:** PostgreSQL
- **AI:** Large language model APIs and structured outputs
- **Version Control:** Git and GitHub
